熊掌笔记 GitHub Gist 同步升级说明

本次修改：
1. Gist 文件名统一为 notes.json，与已创建的 Secret Gist 匹配。
2. 设置页使用 Fine-grained Personal Access Token；Token 仅保存在当前页面内存中，不再写入 localStorage。刷新页面后需重新输入。
3. 同步时先读取云端，再进行三方合并；不同笔记可自动合并。
4. 同一篇笔记在本地和云端都发生不同修改时，保留云端原笔记，并将本地版本另存为“本地冲突副本”。
5. 同步上传后再次读取校验，发现并发写入时提示再次同步。
6. 手动“拉取”会提示确认替换本地数据；“推送”会上传本地数据。
7. 修正本地数据、同步配置、同步基准快照使用不同的 localStorage key。
8. Service Worker 缓存版本升级为 v2，避免继续使用旧缓存。

首次使用：
- 部署/打开更新后的网页。
- 打开设置 → GitHub Gist 同步。
- 输入 Token、Gist ID：269330fed87d8f012a063c709e4cd690。
- 勾选“启用”，保留“自动”选项，点击“双向同步”。
- 在另一台设备也打开同一个 App，输入同一个 Token 和 Gist ID，再点击“双向同步”。

安全提醒：
- 不要把 Token 写入 HTML/JS 源码、Git 仓库或发送给他人。
- 纯前端网页无法对 Token 提供真正的保密存储。本版本只把 Token 放在当前页面内存中；刷新页面后需重新输入，但这仍不能防御页面存在 XSS 时的令牌读取。
- Secret Gist 不是加密存储；建议不要同步密码、证件号等高敏感内容。
- 第一次双向同步前，建议先在 App 设置中导出 JSON 备份。
